    Enablement sweep — what actually goes live this wave

    • Charge Cool goes live fleet-wide. Cloud v2.47.0 sets chillAllEChargeCoolEnabled to true for the fleet (QPD-15793). On All-Electric systems with a Chill, the heat the Chill removes while cooling is now routed into the HeatBattery instead of being wasted. The controller code shipped in the CiC 4.11.0 wave (Controller 6.12.0) and is already in the field; this is the production enablement, so it is customer-visible for All-E + Chill homes now (see the Customer tab).
    • App minimum version raised to 1.60.0. Cloud now rejects installer apps below the floor at commissioning create/start with a 426 (QPD-15812, QPD-15795), and the update banner / admin APIs learn min and latest versions (QPD-15798, QPD-15797, QPD-15800).
    • Thread FW 2.14.0 is bundled in the CiC image (dongle / Chill interface board). It carries an OTA brick-risk fix, a CoAP write-safety fix and Thread-certification work — it ships to whatever runs the 4.14.0-alpha.1 image, i.e. the alpha track only this wave.
    • CiC WiFi / connectivity reliability (WiFi firmware bump, kernel-side chip recovery, roaming, network-switch timeout) is in the 4.14.0-alpha.1 build only — not yet on the customer fleet.

    The alpha CiC firmware goes only to the alpha-test track — do not communicate its behaviour to the wider customer base or installers.

    QPD-152 · Production Incidents / Continuous Improvements — App / Backend 11 tickets

    Quatt’s rolling backend maintenance Epic: production incidents and continuous improvements. This wave it carries the app-version floor enforcement, a gas-pricing incident fix, support-dashboard additions and fleet-config tooling — all in Cloud v2.47.0.

    • Installer app-version floor: raise the app minimum version to 1.60.0 (QPD-15812 no team set); reject sub-floor installer apps at commissioning create/start with a 426 (QPD-15795 Cloud / Backend); extend GET /app-compatibility with min and latest version for the update banner (QPD-15798 Cloud / Backend); expose app version on the admin commissioning list/history and detail (QPD-15797 Cloud / Backend); derive the latest version from fleet adoption via an hourly job instead of a manual config bump (QPD-15800 Cloud / Backend)
    • Gas pricing incident: handle an EEX multi-day TTFWE delivery block that caused production 500s on 2026-08-31 (QPD-15740 no team set); remove the legacy sFTP-based EEX gas-pricing path and its feature flag (QPD-15739 no team set)
    • Support dashboard & monitoring: show Chill interface-board history on the installation view (QPD-15743 Cloud / Backend); alert on missing or incomplete HomeBattery insights data from EnergyOS (QPD-15582 Cloud / Backend)
    • Fleet-config tooling: a generic bulk job (SYNC_CIC_CONFIG) that pushes MQTT config to many CiCs at once (QPD-15835 Cloud / Backend)
    • WiFi / installer fix: Forget WiFi no longer returns 404 for a CiC that has no installation yet, so the installer pre-commissioning flow works (QPD-15767 Cloud / Backend)
    Impact for CS / installers: installers on an app older than 1.60.0 are now blocked at commissioning and prompted to update. The gas-pricing 500s are resolved. The support dashboard shows Chill interface-board history, and Forget WiFi works on not-yet-commissioned CiCs.

    QPD-11880 · Bug Fixing & Fleet Diagnostics 5 tickets

    The embedded team’s rolling bug-fixing and fleet-diagnostics Epic. This wave’s theme is WiFi and dongle connectivity reliability, landing in the CiC 4.14.0-alpha.1 build and bundled Thread FW 2.14.0.

    • WiFi chip crash fixed: bump the SD8987 WiFi firmware (p69.3 → p142.3) so the chip self-recovers from the CSA-during-reassociation race that previously wedged it permanently (QPD-15660 Embedded Systems)
    • Thread stats freeze fixed: resolve a lock-order deadlock in cic-thread-network-manager between the libcoap I/O thread and the device runners that froze all FTD stats at connected=true (QPD-15733 Embedded Systems)
    • Dongle OTA brick risk fixed: OTA rollback was cancelled on the first CoAP connect, so a later fault could brick the dongle — the confirmation is now deferred (QPD-15731 Embedded Systems)
    • Diagnostics: publish per-device CoAP restart counts (last 1h / 24h / lastAt) in thread_devices_stats (QPD-15765 Embedded Systems)
    • Boiler control default: change the OpenTherm thermostat domestic-hot-water enable (ot_tb_dhw_enable) to default on, evaluated for hybrid boiler setups (QPD-15124 Embedded Systems)
    Impact for ops: these address real field failure modes (WiFi chips wedging offline, dongle OTA bricking, frozen Thread stats). They ride the CiC 4.14.0-alpha.1 build and bundled Thread FW 2.14.0, so they reach the alpha track first, not the general fleet, this wave.
