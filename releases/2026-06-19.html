Quatt Ecosystem Release 19.06.2026

CiC 4.8.0-beta.0 Cloud v2.39.2–v2.40.0 Thread FW 2.11.1 Controller 6.9.0 Chill CB FW 2.0.0 ODU FW 2.1

What changed in this revision

Shown only on the staging preview — hidden in production.

  • Phase promotion: 4.8.0-alpha.1 → 4.8.0-beta.0 (alpha → beta). Badge advanced, CiC version + headline date updated to the beta tag (19.06.2026).
  • Paired-product version bumps: none. Bundled components are unchanged — Controller 6.9.0, Thread FW 2.11.1, embedded-apps 1.31.1, Chill control-board FW 2.0.0, ODU FW 2.1; paired Cloud v2.39.2–v2.40.0 (latest v2.40.0, 16.06) and App v1.57.0 also unchanged.
  • Newly-added QPD tickets since the previous tag: none. The quatt-revisions.inc manifest is byte-identical between 4.8.0-alpha.1 and 4.8.0-beta.0, and the beta.0 GitHub changelog is empty — this is a pure phase promotion of the same shipped content.
  • Reverted / removed: nothing.

What's new

  • If you have an All-Electric system and Chill, heat extracted by the Chill will be automatically used to charge the HeatBattery whenever feasible.

Heating performance and reliability

  • Improved connection stability over both Thread and Wi-Fi, reducing momentary dropouts.
  • Connected Chill devices no longer briefly disappear from the app home screen while a background update is running.
  • The Quatt dongle's connectivity light now correctly turns red when the dongle is actually offline.

Bug fixes and maintenance

  • This update also includes general bug fixes, security updates, and improvements to system reliability and connectivity.

Wat is er nieuw

  • Als u een All-Electric systeem met een Chill heeft, wordt de door de Chill onttrokken warmte automatisch gebruikt om de HeatBattery op te laden wanneer dat mogelijk is.

Verwarmingsprestaties en betrouwbaarheid

  • Verbeterde verbindingsstabiliteit via zowel Thread als wifi, met minder kortstondige onderbrekingen.
  • Verbonden Chill-apparaten verdwijnen niet langer kortstondig uit het startscherm van de app terwijl er op de achtergrond een update draait.
  • Het verbindingslampje van de Quatt-dongle wordt nu correct rood wanneer de dongle daadwerkelijk offline is.

Foutoplossingen en onderhoud

  • Deze update bevat daarnaast algemene foutoplossingen, beveiligingsupdates en verbeteringen aan de betrouwbaarheid en connectiviteit van het systeem.
Scope: CiC 4.8.0-beta.0 diffed from 4.7.1 (beta release; promoted from 4.8.0-alpha.1). This wave bundles Controller 6.9.0, Thread firmware 2.11.1 and embedded-apps 1.31.1 into the CiC image, and pairs Cloud v2.39.2 + v2.40.0 (v2.39.3 hotfix folded in). No App release shipped in this window — the latest App build remains v1.57.0 from the 04.06.2026 wave.
alpha.1 → beta.0 delta: pure phase promotion — the quatt-revisions.inc manifest is byte-identical between the two tags and the beta.0 changelog is empty. No component bumps and no new Jira tickets; the same shipped content advances from alpha to beta.
Earlier alpha.0 → alpha.1 delta (folded into this wave): Chill control-board firmware bumped 1.0.10 → 2.0.0, plus an embedded-apps point fix (1.31.0 → 1.31.1) disabling the cic-chill RX watchdog. No new Jira tickets — both are Chill-stability follow-ups.

1 · All-Electric & commissioning enhancements ALL-E | Commissioning & B2B Enhancements

  • CH water-temperature preheating ("holdTemperature") during commissioning to cut HeatCharger charging wait time — CiC wiring + backend ingest & Grafana (QPD-14216, QPD-14219)
  • Commissioning M6: 3-way valve position check replaces the obsolete Boost test (QPD-14061)
  • Always-surface All-Electric diagnostics per screen — banners decoupled from test pass/fail; diagnostics registry advanced to v9.2 (sensor-failure severities, four-way-valve suppression, title renames) (QPD-14372, QPD-14490)
  • HeatCharger firmware-update progress indicators (M13) (QPD-14093)
  • DHW flow-restrictor warning surfaced as a context alert, with exposed flow threshold (S20) (QPD-14102)
  • Cooling-test tightening: minimum duration raised to 7 min, success criteria + recirculation detection reworked, flow test extended (QPD-14261, QPD-14281, QPD-14339)
  • Stuck-commissioning fixes: corrected expected power during ODUv2 commissioning; orphaned legacy commissioning no longer 404s the installer's in-progress list (QPD-14437, QPD-14509)
Impact for commissioning/installers: All-Electric commissioning is faster (CH preheating), more informative (per-screen diagnostics, firmware progress, flow thresholds) and more robust (cooling-test criteria, fewer stuck states). The Boost test is gone — expect the 3-way-valve check in its place.

2 · ODUv2 over-the-air updates — validation & hardening ODUv2 | Heatpump OTA Update

  • ODUv2 OTA flow validated end-to-end and update-gating hardened; QA sign-off on the firmware-update feature (QPD-12078, QPD-14126)
  • New devices_update commissioning mode triggers ODU updates after Identification (QPD-14126)
  • New watchdog code for ODUs while updating; hp_connected flags held at their previous state during an ODU update (no false disconnect) (QPD-14289, QPD-14431)
  • Backend OTA capability checks for outdoor units added in Cloud v2.39.2
Impact for ops: ODUv2 OTA is validated and gated for this build. Watch rollout dashboards during the first 4.8.0 waves; ODU FW stays 2.1.

3 · Chill control-board OTA hardening CHILL | Control Board OTA Update

  • Amitime OTA-over-Modbus integrated into cic-chill; control-board FW + EEPROM now updated together in one chained flow (QPD-10346, QPD-14230)
  • 'Connected' stays fresh during OTA; no false UPLOADING_IMAGE when a device is cut in line; no spurious WARNING_IN_MAINTENANCE while an update is merely PENDING (QPD-14231, QPD-14290, QPD-14275)
  • Strict Chill control-board update-state prerequisite enabled at CiC 4.6.0 (blocks on FAILED / in-progress / unreadable for all three boards) (QPD-14400)
  • Commissioned Chills no longer disappear from the app home screen when CiC stats are momentarily incomplete; Chill reboot logic fixed (QPD-14302, QPD-14353)
  • HeatCharger no longer remains stuck in download mode on slow flash writes (QPD-14233)
  • alpha.1: bundled Chill control-board firmware advanced to 2.0.0, paired with an embedded-apps fix disabling the cic-chill RX watchdog (no Jira key) to stop spurious resets during control-board OTA
Impact for CS: Chill OTA support calls ("disappeared from the app", "stuck updating") should drop. The connectivity-LED fix removes a false "offline" signal customers reported. The alpha.1 control-board firmware 2.0.0 + RX-watchdog change targets remaining Chill stability during updates — watch Chill OTA dashboards on this build.

Networking and connectivity

  • WiFi command handling ported Python → C++ libnm; follow-up memory-leak fix (NMClient GMainContext never serviced between WiFi commands) (QPD-14148, QPD-14564)
  • Thread network-manager hang fixed (session-mutex / watchdog); cic-cloud-proxy MQTT reconnect interval tightened (QPD-14099, QPD-14155)
  • P1 telegrams exposed over CoAP /p1 + /config role byte (v2); CoAP features version-gated for older dongle firmware (QPD-13905, QPD-13559)
  • Redis robustness: hiredis read-buffer desync detection + reconnect, binary-safe Redis::get (QPD-13986, QPD-14315)
  • Dongle / Thread FW 2.11.1: detect CoAP client disconnect via inbound-traffic inactivity; default to Extender role to avoid reboot after pairing (QPD-14470, QPD-14472)
  • Installer LED UX (Rev7): state machine reworked, modem fault shown only when backend unreachable, brightness reduced, no false 'connected to backend' before provisioning (QPD-13758, QPD-14384, QPD-14277)

Field reliability and customer-impacting fixes Controller 6.9.0 + CiC

  • Controller starts with both outdoor units disconnected so the boiler can still heat (QPD-14280)
  • All-Electric cooling capacity model integrated; Chill + All-Electric support power-demand estimator unified (QPD-13343, QPD-14186)
  • 3-minute compressor cooldown treated as a recoverable lockout; DHW pump runs full speed when inlet is above target (QPD-14373, QPD-14374)
  • Human-readable pump level corrected; lab Chills suddenly disconnecting fixed (stale-ping sweep) (QPD-14116, QPD-13625)
Boost Mode is still a flagged-off prototype. QPD-14373 / QPD-14374 sit under the Boost Mode epic but ship here as general controller fixes (compressor lockout, DHW pump). Do not announce Boost Mode — verify flag state before any comms.

Fleet operations, serviceability & tech debt

  • Full decommission / factory reset: quatt-factory-reset oneshot + MQTT factory_reset command (QPD-13989)
  • Mender deployment-group creation optimised for fleet rollouts; admin endpoint to trigger a manual CiC firmware deployment via Mender (QPD-14566, QPD-14271)
  • Build traceability: AUTOREV in quatt-revisions + per-app version logging at startup (QPD-13837)
  • cic-cloud-webserver redesigned to track messagespec; live-stats page made mobile-friendly; stats gzipped on /cicZipStats; simulation tools consolidated; liveview kept enabled during commissioning (QPD-13928, QPD-14380, QPD-13788, QPD-13911, QPD-14378)
  • Cloud platform: ECS monitoring Grafana dashboards (reverted then restored with a CloudWatch filter fix), MemoryDB-over-Heroku proxy migration, office dashboard feed job; flaky recommissioning E2E pollution fixed (QPD-14456, QPD-14460, QPD-14493)
