    QPD-152 · Production Incidents / Continuous Improvements — App / Backend 15 tickets

    Quatt’s rolling production-incident and continuous-improvement Epic for app and backend. This wave it carries commissioning reliability fixes, EMS / HomeBattery data onboarding, an admin-tooling change, and backend / telemetry hardening (Cloud v2.45.0), plus a batch of App v1.62.0 changes: a customer-visible All-Electric fix, Wi-Fi commissioning reliability, and app tooling.

    • Commissioning reliability: the “Verbind CiC” Wi-Fi connect step now shows clear progress and failure feedback instead of a silent 60–90s wait, and repeated presses no longer fire duplicate requests (QPD-14487 Cloud / Backend); the CiC identification step no longer intermittently blocks commissioning (QPD-15283 Cloud / Backend)
    • EMS / HomeBattery onboarding: solar and battery data synced for specific HomeBattery buildings on the AlphaESS portal (QPD-15561 Cloud / Backend, QPD-15669 Cloud / Backend)
    • Admin tooling: installation deletion enabled in production for an allowlist of users (QPD-15605 Cloud / Backend)
    • Backend hardening: the weather config no longer sends a dead weather topic for an unresolvable postcode (QPD-15500 Cloud / Backend); permission-denied responses now log as warnings with the user id and a static message (QPD-15584 Cloud / Backend); the filtered room and ambient temperatures are ingested into ClickHouse for analysis (QPD-15609 Cloud / Backend); unit-test CI sped up (QPD-15551 Cloud / Backend)
    • Backend infrastructure (no ticket): telemetry storage moved to Athena / S3 tiering with daily firehose compaction.
    • App — customer-visible fix (App v1.62.0): the All-Electric settings screen now shows a newly saved night window immediately, instead of the old one until the screen is reopened (QPD-15597 App) — see the Customer tab
    • App — commissioning Wi-Fi (App v1.62.0): the Wi-Fi connect step now shows a spinner, disables the button while in-flight and renders connecting / verifying plus failure reasons (QPD-15538 App); Forget Wi-Fi no longer fails during commissioning because the acting role was derived from the navigation stack (QPD-15607 App); a forgotten network reappears in the scan list (QPD-15608 App); and the connected-Wi-Fi row no longer flashes empty right after a forget (QPD-15697 App)
    • App tooling: an App Lead playbook / skill for the team (QPD-15333 App)
    Impact for ops / CS: the commissioning fixes improve installer success, and the data syncs onboard specific HomeBattery installations. The All-Electric night-window fix is customer-visible and live in App v1.62.0. The remaining items are backend- or app-internal and need no customer action.

    QPD-11880 · Bug Fixing & Fleet Diagnostics 5 tickets

    The rolling bug-fixing and fleet-diagnostics Epic. This wave’s headline is cellular-modem recovery, alongside restored update polling, richer per-device telemetry, and a HeatCharger-discovery fix.

    • Modem recovery: cellular modems stuck in the download (EDL) mode are now detected and recovered by briefly dropping the modem power supply. Around 887 CiCs were in this dark-modem state and can now self-heal (QPD-15598 Embedded Systems)
    • Update polling restored: Mender update-check timeouts are restored so a CiC keeps polling for over-the-air updates without dropping long-lived connections (QPD-15595 Embedded Systems)
    • Fleet diagnostics: the CiC now publishes a last-received timestamp per external device (boiler, thermostat, HeatCharger, outdoor unit) (QPD-15437 Embedded Systems)
    • Heating control: noisy room-temperature readings are handled gracefully so sensor noise no longer makes the outdoor unit switch needlessly between states (QPD-15361 Systems Control)
    • Commissioning: the HeatCharger config is now published before identification, so HeatCharger discovery no longer deadlocks on flag-gated CiC firmware (QPD-15592 Cloud / Backend)
    Impact for ops / CS: substantially better fleet connectivity and diagnostics — stuck cellular modems can recover on their own, update polling is restored, and All-Electric HeatCharger discovery no longer stalls. The CiC-side items reach only the beta track this wave; the HeatCharger-config fix (Cloud) is live.

    QPD-11732 · All-E | Boost Mode Feature 2 tickets

    Boost Mode lets an All-Electric system quickly restore hot water when the HeatBattery is depleted. This wave fixes two display / reporting issues around the boost countdown and button state.

    • The first boost status no longer reports an end time from an unsynced local clock, so the app no longer briefly shows a countdown above 30:00 (QPD-14818 Embedded Systems)
    • A cached failed outcome no longer masks a disabled state, so the boost button no longer stays enabled after a mid-boost exit (QPD-15470 Cloud / Backend)
    Impact for CS: more accurate boost countdown and button behaviour for All-Electric customers where Boost Mode is enabled. The CiC-side fix ships on the beta track this wave.

    QPD-149 · Embedded Technical Debt 1 ticket

    The embedded technical-debt Epic. This wave it carries a substantive connectivity improvement.

    • Smarter cellular (LTE) failover: LTE is never disabled while no Wi-Fi or Ethernet path is working, is enabled faster when there is no alternative, and an interface is marked unreachable only after three consecutive failed checks so a single blip no longer reshuffles routes or drops connections (QPD-11692 Embedded Systems)
