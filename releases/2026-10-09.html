This wave extends the controller to all-electric systems and dual tariffs, and lands most of the backend for the thermostat live override — but the customer-facing parts stay pilot / develop-only.

    • Controller (6.15.1): extend predictive heating to all-electric systems, using the central-heating backup heater as an MPC input instead of the boiler (QPD-14792 Systems Control); synthesize a day/night electricity-price trajectory so predictive heating can use a double (dual-rate) tariff (QPD-15687 Systems Control)
    • Thermostat live override & setpoint source (backend, Cloud v2.49.0): send the live override in the thermostat schedule payload behind a minimum-CiC-build gate (QPD-16050 Cloud / Backend); ingest and expose the CiC-reported active setpoint source and resolved setpoint on /me/cic and the admin detail (QPD-15824 Cloud / Backend, QPD-16051 Cloud / Backend, QPD-16083 Cloud / Backend); refuse an override while the CiC is offline, allow an override with an empty week, keep a tapped override until the CiC confirms it, and widen room setpoints to 16–30 °C (QPD-16085 Cloud / Backend, QPD-16096 Cloud / Backend, QPD-16103 Cloud / Backend, QPD-16127 Cloud / Backend); expose CiC reachability/last-seen, settle the no-schedule expiry rule, demote a refused-offline-override log, fix the schedule payload that sent a forbidden liveOverride, and stabilise the e2e (QPD-16090 Cloud / Backend, QPD-16087 Cloud / Backend, QPD-16111 Cloud / Backend, QPD-15848 Cloud / Backend, QPD-16069 Cloud / Backend)
    • Pilot enablement & exposure (backend): a script to bulk-import predictive-heating models and push them to their CiCs (QPD-15950 Cloud / Backend); expose avoid-gas-boiler-use to non-predictive Hybrid CiCs above a minimum firmware build (QPD-15947 Cloud / Backend)
    • Message spec (2.87.0): add the optional liveOverride field to the thermostat schedule schema — the device side of the app live override (QPD-15822 Cloud / Backend)
    Shipped but NOT live — do not communicate: predictive heating stays pilot-cohort only; the thermostat live override is enabled on develop only (also behind a minimum-CiC-build gate) with no new App UI this wave.     QPD-152 · Production Incidents / Continuous Improvements — App / Backend 16 tickets

    Quatt’s rolling backend maintenance Epic: production incidents raised by the Quality team and fixed by SW&Infra. This wave (all in Cloud v2.49.0) carries boiler-type data-integrity fixes, HomeBattery import/savings handling, commissioning robustness, and a batch of log-noise and database-stability fixes.

    • Boiler-type data integrity: the On/Off boiler choice in new commissioning was not written to installation.boilerType (the config publish sent null) (QPD-14144 no team set); an admin edit of the boiler type did not sync deviceBoiler.type (QPD-15306 Cloud / Backend); and 13 production installations with a mismatch were backfilled (QPD-14147 Cloud / Backend)
    • HomeBattery: raise the import row limit from 1000 to 10000 (QPD-16012 Cloud / Backend); round incl-VAT savings to the nearest cent instead of down (QPD-16070 Cloud / Backend)
    • Commissioning / ingestion: commissioning skipped the ODU device update on CiCs shipped with factory firmware 4.6.0 (QPD-16108 Cloud / Backend); EMS v1 building stats with a null state-of-charge were rejected and dropped to the dead-letter queue (QPD-16107 Cloud / Backend)
    • Database & reliability: a production MySQL prepared-statement ceiling hit under task overlap (QPD-16055 Cloud / Backend); event-driven BullMQ jobs ignored their retry config (QPD-15710 Cloud / Backend)
    • Log-noise & housekeeping: production error-log cleanup (double-response bug, ClickHouse buffer loss, noise demotion) (QPD-15749 Cloud / Backend); demote TariffDateError and deprecated-endpoint calls out of error/Sentry (QPD-16117 Cloud / Backend, QPD-16146 Cloud / Backend); expose settingsType on the settings history header (QPD-16004 Cloud / Backend); lower the CH max water-temperature minimum to 25 °C (QPD-16098 no team set); pull CI test images from mirror.gcr.io (QPD-16089 no team set)
    Impact for CS: the boiler-type fixes correct installation records going forward and backfill the 13 affected installations — no customer action. The HomeBattery savings now round to the nearest cent (a small, customer-visible accuracy change on the savings view). The rest is backend log-noise and stability work with no field action.

    QPD-11880 · Bug Fixing & Fleet Diagnostics 6 tickets

    The embedded team’s rolling bug-fixing and fleet-diagnostics Epic. This wave adds an Thread link-quality diagnostic, a commissioning sensor-safety fix, two Thread network-manager fixes, a crash-context capture and an OTA robustness fix.

    • Commissioning sensor safety: a shorted PT1000 supply sensor read about −0.5 °C and passed as connected, letting commissioning complete without a sensor; implausible codes are now rejected and the stale temperature cleared (QPD-16044 Embedded Systems)
    • Thread network manager: stop crashing with “InvalidState” when the commissioner is restarted while the CiC is detached (QPD-16062 Embedded Systems); stop logging failed joiner attempts as “successfully joined” (QPD-16063 Embedded Systems)
    • Link diagnostics: publish per-Thread-device 802.15.4 MAC counters (CCA/busy-channel/retry) so a lossy link can be traced to a busy channel or unacknowledged frames — exposed over CoAP by the dongle and gathered by the CiC (QPD-15736 Embedded Systems)
    • OTA robustness: report a bad image signature as a permanent failure so the CiC stops retrying a permanently bad image (QPD-15976 Embedded Systems)
    • Crash diagnostics: capture the A926 OpenTherm engine crash context before the forced CiC reboot, so the reboot can be diagnosed (QPD-15890 Embedded Systems)
    Impact for installers / CS: the shorted-sensor fix prevents a commissioning from passing without a working supply sensor. The Thread, OTA and crash-context items are reliability and diagnostics work on the alpha firmware — no field action while the build is on the alpha track.
