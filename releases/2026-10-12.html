What changed in this revision

Shown only on the staging preview — hidden in production.

Promotion — beta.0 → 4.16.0 GA (same commit). This revision promotes the 4.16.0 wave from CiC 4.16.0-beta.0 to the general release CiC 4.16.0. The two tags point at the identical commit (322ae4dc) and the build is byte-identical, so there is no change to the ticket content, tiers or the engineering table — only the phase (beta → stable / GA), the badge, and the CiC version label move. Delta vs the currently-published version (the beta entry on main, PR #42): phase beta → stable; no paired-product version bumps (Cloud v2.49.0 + v2.50.0 and App v1.64.0 unchanged); no newly-added tickets (the GA tag re-tags the beta.0 commit, so the 4.15.0 → 4.16.0 diff is identical); nothing reverted or removed since the beta revision.

Phase & date. The target tag 4.16.0 carries no pre-release suffix, so it is the production-ready general release — badge stable (GA). It is production-ready by definition and may deploy to the fleet at any time; the GA call does not depend on whether a GitHub Release is published or whether fleet rollout has started. Headline date 2026-10-12 = the 4.16.0 tag commit's committer date (no GitHub Release is published for the 4.16.0 tag; it re-tags the beta.0 / alpha.2 commit).

New functions — the “Don’t use gas” reactive avoid-gas setting (QPD-15897 controller + QPD-15947 Cloud gate, reachable at CiC 4.16.0) and HomeBattery renaming (QPD-16071). No versions or phase words in customer copy. This page is the one-and-only 4.16.0 entry, so these first-time customer features stay in Tier 1 for the wave they ship live in.

Release timeline

Live from the shared Quatt release calendar.

    New functions

    • You can now choose to avoid using the gas boiler on Quatt Hybrid systems: switch on the “Don’t use gas” setting to give the heat pump priority for heating. The gas boiler still steps in when it is needed for safety or when the heat pump cannot deliver enough heat on its own.
    • You can now give your HomeBattery a name of your own in the app.

    Heating performance and reliability

    • Everyday heating and comfort behaviour is unchanged in this release.

    Bug fixes and maintenance

    • Improved Wi-Fi connection reliability, including better recovery from network problems.
    • HomeBattery savings amounts now round to the nearest cent.
    • General reliability and maintenance improvements behind the scenes.

    Nieuwe functies

    • Het dagelijkse verwarmings- en comfortgedrag is ongewijzigd in deze release.

    QPD-11880 · Bug Fixing & Fleet Diagnostics 8 tickets

    The embedded team’s rolling bug-fixing and fleet-diagnostics Epic. This wave adds a WiFi-recovery fix, a Thread link-quality diagnostic, a commissioning sensor-safety fix, two Thread network-manager fixes, a crash-context capture and an OTA robustness fix.

    • WiFi recovery (added late in the wave): the WiFi driver was treating 5 missed EAPOL handshakes as a firmware hang, and the recovery power-cycle could wedge the CiC; it now power-cycles only on a real firmware hang and unloads the driver first (QPD-16123 Embedded Systems)
    • Commissioning sensor safety: a shorted PT1000 supply sensor read about −0.5 °C and passed as connected, letting commissioning complete without a sensor; implausible codes are now rejected and the stale temperature cleared (QPD-16044 Embedded Systems)
    • Thread network manager: stop crashing with “InvalidState” when the commissioner is restarted while the CiC is detached (QPD-16062 Embedded Systems); stop logging failed joiner attempts as “successfully joined” (QPD-16063 Embedded Systems)
    • Link diagnostics: publish per-Thread-device 802.15.4 MAC counters (CCA/busy-channel/retry) so a lossy link can be traced to a busy channel or unacknowledged frames — exposed over CoAP by the dongle and gathered by the CiC (QPD-15736 Embedded Systems)
    • OTA robustness: report a bad image signature as a permanent failure so the CiC stops retrying a permanently bad image (QPD-15976 Embedded Systems)
    • Crash diagnostics: capture the A926 OpenTherm engine crash context before the forced CiC reboot, so the reboot can be diagnosed (QPD-15890 Embedded Systems)
    Impact for installers / CS: the WiFi-recovery fix improves connection reliability (customer-perceivable — see the Customer tab). The shorted-sensor fix prevents a commissioning from passing without a working supply sensor. The Thread, OTA and crash-context items are reliability and diagnostics work riding the CiC 4.16.0 firmware to the fleet — no field action needed.
