Quatt Ecosystem Release 17.06.2026

CiC 4.8.0-alpha.0 Cloud v2.39.2–v2.40.0 App v1.57.0 (unchanged) Thread FW 2.11.1 Controller 6.9.0 cpp-apps 1.31.0

What's new

  • Chill devices now stay visible on the app home screen during brief connection gaps or while their software is updating, instead of disappearing momentarily.
  • The connectivity light on Chill and the wireless dongle now shows red correctly when a device is actually offline, rather than staying white.

Heating performance and reliability

  • Your system now keeps heating through the boiler when the outdoor units are temporarily disconnected.
  • Fewer brief heating interruptions: a short compressor cooldown is now treated as a temporary pause rather than a fault.
  • Improved hot water behaviour when the incoming water is already warm.
  • More reliable connections for Chill and other wirelessly connected Quatt devices.

Bug fixes and maintenance

  • This update also includes general bug fixes, security updates, and improvements to system reliability and connectivity.

Wat is er nieuw

  • Chill-apparaten blijven nu zichtbaar op het beginscherm van de app tijdens korte verbindingsonderbrekingen of terwijl de software wordt bijgewerkt, in plaats van even te verdwijnen.
  • Het verbindingslampje van de Chill en de draadloze dongle laat nu correct rood zien wanneer een apparaat echt offline is, in plaats van wit te blijven.

Verwarmingsprestaties en betrouwbaarheid

  • Je systeem blijft nu via de ketel verwarmen wanneer de buitenunits tijdelijk niet verbonden zijn.
  • Minder korte onderbrekingen van de verwarming: een korte afkoeling van de compressor wordt nu als tijdelijke pauze behandeld in plaats van als storing.
  • Verbeterd gedrag voor warm tapwater wanneer het inkomende water al warm is.
  • Betrouwbaardere verbindingen voor Chill en andere draadloos verbonden Quatt-apparaten.

Foutoplossingen en onderhoud

  • Deze update bevat daarnaast algemene foutoplossingen, beveiligingsupdates en verbeteringen aan de betrouwbaarheid en connectiviteit van het systeem.
Scope: CiC diffed 4.7.1 → 4.8.0-alpha.0 (the alpha is treated as a general release per the run request). Paired Cloud v2.39.2 + v2.40.0; Wireless Platform / Thread FW 2.11.1. No new App release this wave — the App remains on v1.57.0 (shipped with the 04.06 wave). Bundled in the CiC image: cpp-apps 1.31.0, Controller 6.9.0, messagespec 2.76.1, Thread device FW 2.11.1.

1 · Firmware over-the-air updates move toward the field ODUv2 OTA · CHILL Control Board OTA · HeatCharger

  • ODUv2 heat-pump OTA flow implemented on the CiC, with a dedicated update watchdog and connection-state handling during the update (QPD-14126, QPD-12078, QPD-14289, QPD-14431)
  • No false UPLOADING_IMAGE / PENDING_UPDATE state for devices queued behind an active OTA on a flaky link (QPD-14290)
  • Chill control-board OTA hardened: firmware + EEPROM updated together in one chained flow; 'connected' stays fresh during the update; screen-vs-network-state mismatch fixed (QPD-10346, QPD-14230, QPD-14231)
  • Chill no longer reports WARNING_IN_MAINTENANCE while an update is only queued (PENDING) rather than actively uploading (QPD-14275)
  • Empty Thread firmware version reporting fixed (OTA-only version handling, SRP TXT cache path dropped) (QPD-14021, QPD-14103)
  • HeatCharger firmware-update progress now published; updates no longer restart on slow flash writes (was stuck ~30 min) (QPD-14093, QPD-14233)
Impact for ops/CS: This is the floor that brings ODUv2 OTA toward the field. Expect fewer Chill OTA support calls ("stuck updating", false "in maintenance"). Watch rollout dashboards during the first waves.

2 · All-Electric & Chill commissioning wave ALL-E | Commissioning & B2B Enhancements · CHILL | Field Test Stability

  • New 3-way valve position check commissioning test replaces the obsolete Boost test (Controls + backend) (QPD-14061)
  • CH water preheating during commissioning ("holdTemperature") to cut HeatCharger charging wait time — wired end to end across CiC + backend (QPD-14216, QPD-14219)
  • Cooling commissioning test tightened: minimum duration raised to 7 minutes, success criteria and recirculation detection reworked, flow test extended (QPD-14261, QPD-14281, QPD-14339)
  • Diagnostics registry v9.2: sensor-failure severities raised to error, four-way-valve alert suppressed, installer-facing title renames (QPD-14490)
  • ALL-E diagnostics always surfaced per screen (decoupled from test pass/fail); DHW flow-restrictor warning via context alerts (QPD-14372, QPD-14102)
  • Live view stays enabled during commissioning; correct expected power for ODU v2 + new firmware (QPD-14378, QPD-14437)
  • Fix: a single orphaned legacy commissioning no longer 404s the installer's entire in-progress list (QPD-14509)
Impact for commissioning/installers: Commissioning is faster (CH preheating) and more informative (always-on diagnostics, severity-corrected alerts, clearer titles). The Boost test is gone — use the 3-way valve check.

3 · Networking, connectivity & the wireless dongle Dongle | SW Improvements · Thread FW 2.11.1

  • Thread network-manager hang fixed; stale-ping sweep now runs regardless of session state; session mutex no longer held across the user DISCONNECTED callback (QPD-14099, QPD-13625)
  • WiFi command handlers ported Python → C++ libnm; NMClient GMainContext memory leak fixed; GMainContext now pumped from the listen watchdog (QPD-14148, QPD-14564)
  • Parsed P1 telegrams exposed over CoAP /p1 + /config v2 role byte; CoAP features version-gated for older dongle firmware (QPD-13905, QPD-13559)
  • cic-cloud-proxy MQTT reconnect interval tightened (QPD-14155)
  • Wireless Platform 2.11.1: dongle defaults to Extender role to avoid a reboot after first pairing; CoAP client-disconnect detected via inbound-traffic inactivity; LED shows red (not solid white) when actually disconnected (QPD-14472, QPD-14470)

4 · Field reliability and customer-impacting fixes Controller 6.9.0 + Cloud

  • Controller starts up and lets the boiler heat even when both outdoor units are disconnected; hp-connected-not-populated now treated as disconnected (QPD-14280, QPD-14507)
  • A 3-minute compressor cooldown is now treated as a recoverable lockout; DHW pump runs full speed when inlet is above target (QPD-14373, QPD-14374)
  • Chill device setpoints are only written once the Chill is connected (reboot-logic fix); human-readable pump level corrected (QPD-14353, QPD-14116)
  • Cloud: commissioned Chills no longer vanish from the app home screen when CiC stats are momentarily incomplete (QPD-14302)
  • cic-cloud-metrics hiredis read-buffer desync fixed; Redis::get made binary-safe (QPD-13986, QPD-14315)
Impact for CS: The "my Chill disappeared from the app" reports should stop. Heating continuity during outdoor-unit dropouts improves comfort during field incidents.

5 · LED UX for installers LED UX design for installers

  • Rev7 LED state machine implemented (QPD-13758)
  • LED no longer shows 'connected to backend' while the CiC is only provisioning (registering credentials) (QPD-14277)
  • Modem-fault LED shown only when the backend is genuinely unreachable; overall LED brightness reduced, S5 idle dimmed to 10% (QPD-14384)

6 · Fleet operations, serviceability & tech debt

  • Admin: manual CiC firmware deployment endpoint (Mender API) + better Mender deployment groups for fleet rollouts (QPD-14271, QPD-14566)
  • Full decommission / factory reset (quatt-factory-reset oneshot + MQTT command) (QPD-13989)
  • ZipStats telemetry: gzip stats published on /cicZipStats (QPD-13788)
  • Build traceability (AUTOREV in quatt-revisions.inc, app version logged at startup); cic-cloud-webserver redesign + mobile-friendly live-stats page (QPD-13837, QPD-13928, QPD-14380)
  • Controls: All-E cooling capacity model integrated, support power-demand estimator unified, simulation tools consolidated (QPD-13343, QPD-14186, QPD-13911)
  • Cloud platform: ECS monitoring Grafana dashboard (reverted then restored with a CloudWatch filter fix); flaky recommissioning E2E fixed (QPD-14456, QPD-14460, QPD-14493)
